# Olympic-Games-Analytics-Dashboard
🏅 Olympic Games Analytics Dashboard

An interactive Power BI dashboard built to analyze Olympic Games data and generate insights related to athletes, countries, sports, and medals.

📊 Dashboard Features

- Total Athletes Analysis
- Country-wise Medal Distribution
- Medal Trend by Year
- Athlete Performance Insights
- Gender Participation Analysis
- GDP vs Medal Correlation
- Interactive Filters & Slicers

🛠 Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling

📌 Key Insights

- Countries with higher GDP generally perform better in Olympics.
- Aquatics and Athletics dominate overall medal counts.
- Male participation is higher, but female participation has grown significantly over time.

🎯 Skills Demonstrated

- Data Cleaning & Transformation
- Interactive Dashboard Design
- KPI Building
- DAX Measures
- Data Storytelling
